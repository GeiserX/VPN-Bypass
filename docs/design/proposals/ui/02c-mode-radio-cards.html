2CRouting mode as three cards in a radio group

Each mode gets a card with a small diagram of where traffic goes: blue through the VPN, green direct, purple through a proxy. Under it sit a radio button, the mode name and one sentence. The layout follows the Appearance choice in System Settings, and the current mode has the accent outline. Clicking another card opens the sheet. Navigation moves into a native toolbar in all four alternatives, so the page buttons no longer look like the mode.

Good. You see how the modes differ before reading a word, which helps a first-time user most. Bad. It is the tallest of the four and pushes the list down on every visit, for a setting most people change once.
