12The dropdown's mode switch becomes a native segmented control with all three modes

Today the dropdown draws its own pair of radio-style buttons, Bypass and VPN Only. In Custom mode they are replaced by a capsule and a plain "Switch to Bypass" link, so from Custom the only way out is Bypass, and Custom cannot be picked from the dropdown at all. The proposal puts all three modes in one native segmented control, the same in every mode. Picking a different mode still asks first, with the alert the app shows today.
