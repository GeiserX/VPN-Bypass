2The routing mode stops looking like a tab

The Settings window has two rows of identical green pills. The top row changes how all traffic is routed; the row under it only switches pages. Clicking VPN Only to look at that list asks to switch the mode for the whole Mac, and there is no way to view or edit the other mode's list without switching. The proposal moves navigation into a native toolbar and shows the mode as a setting with a Change… button that explains each choice before switching.
