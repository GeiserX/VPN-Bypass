4Proxy rules say which apps they reach, and the port reads right

In Custom mode a rule that points at a proxy route only affects apps set to use that proxy. The screen draws it the same way as a Direct or VPN rule, which applies to every app; the difference hides in an info icon that only speaks on hover. On the Routes tab the local address prints as 127.0.0.1:18.168 (as in the docs screenshot) because the port goes through locale number formatting (RoutesTab.swift:368). Typed into a browser's proxy settings, that address does not work.
