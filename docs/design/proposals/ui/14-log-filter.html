14The log gets a level filter and a search field

Settings > Logs is one list, newest first. A warning such as a dropped tunnel or a failed DNS lookup scrolls past between routine lines, and the only tools are Copy and Clear. The 4.9.0 socket verb logs already filters by level; the app cannot. The proposal adds a native segmented control (All, Warnings, Errors) and a search field above the list, with a line saying how many entries match.
