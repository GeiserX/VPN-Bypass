7Group what is routed by what the user added

The dropdown shows Active Services as chips, then Active Routes as raw kernel destinations, four at a time. Telegram shows up in both. The four rows are whatever sorts first, and in VPN Only mode they are the app's own catch-alls, which the badge counts as routes. The proposal merges both cards into one list, one row for each service or domain the user added, with its route count. A source that resolved to nothing gets a warning. The catch-alls become one line that is not counted.
