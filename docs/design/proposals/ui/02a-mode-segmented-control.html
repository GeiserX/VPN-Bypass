2ARouting mode as a segmented control in a settings group

A titled "Routing mode" group at the top of the list page holds a native segmented control with the three modes. One line under it says what the current mode does. Navigation moves into a native toolbar in all four alternatives, so the page buttons no longer look like the mode.

Good. All three modes are in view and one click away, in the control macOS uses for a few choices. Bad. A segmented control normally acts on the click, so the sheet that follows is a small surprise, and the control lives only on the list page.
