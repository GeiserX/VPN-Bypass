15Changes made through vpnb or an AI agent show up in the app

An agent or a script can add domains, turn services on and switch modes through the vpnb socket. The app runs the same code as its own buttons and logs the same lines, so the list just changes and nothing says it came from outside. Someone who lets an agent manage the app has to open the log and guess which lines were theirs. The proposal tags socket changes in the log and adds one line to the dropdown footer after an outside change.
