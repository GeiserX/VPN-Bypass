2DRouting mode as a menu in the window title area

The mode leaves the page and sits at the right end of the title bar as a toolbar menu button that reads "Mode Bypass". Its menu checks the current mode and gives each one a short description. The page starts straight at the list. Navigation moves into a native toolbar in all four alternatives, so the page buttons no longer look like the mode.

Good. The mode shows on every page and takes no room in the content. Bad. People read the title bar as window chrome, so the setting with the widest effect becomes the easiest to miss, and the description lives only in the menu.
