4Settings navigation: a sidebar where every page stays in its place

Before: the toolbar holds 6 or 7 items depending on the mode (SettingsView.swift:61-66), Custom swaps Domains and Services for Rules and Routes, and VPN Only drops Services, so Lookups, General, Logs and Info shift left (the pair below); the gap between items drops from 4 to 0 at seven (:145). The window is fixed at 580×680 (:88). After: a sidebar with three groups. Pages for another mode stay listed, greyed, and open read-only with one line saying which mode uses them. The mode popup sits at the top of the sidebar. The window resizes, so long lists use the height.

The sidebar never changes shape: only which items are grey. Mode-dependent pages stay one click away, and proposal 2's "later step" (the inactive mode's list shown read-only) comes with it.
