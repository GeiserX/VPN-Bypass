7New ideas where they would live: the site you are on, Pause, and "where does this site go?"

Three of the ideas in section 5, drawn in the recommended system. None needs a Network Extension. The suggestion row reads the front browser tab through Apple Events (one Automation prompt per browser). Pause is drawn in Bypass, where it removes the app's routes and puts them back on a timer; VPN Only offers no Pause, because removing its routes would send listed sites outside the VPN. The path check reads the route the kernel picks and whether the site answers on 443 that way, instead of a ping.

The check opens a TCP connection to port 443 and reads its source address with getsockname, so sites that block ping still get an answer. A control address the app does not route must come back the other way, or the result says the check is broken.
