## Before you upgrade

6.0 is a major release. Your settings, lists and services carry over. Five things change for you.

1. **Domains written with a leading dot become wildcards.** Before wildcards, `.example.com` meant "this domain and every subdomain". On first launch 6.0 rewrites each such entry as `*.example.com`. It routes the same names as before. With notifications on, that launch sends one notification naming the entries it changed. Status lists them at the top until you dismiss the note (`vpnb status` prints them too).
2. **The first launch asks for your administrator password once.** The privileged helper goes from 2.5.0 to 2.6.0, and the app reinstalls it.
3. **Settings has a sidebar.** It no longer changes when you switch mode. Info is now About. The global SOCKS5 proxy moved under Advanced in General. Custom mode hides it, so use Routes there. Auto DNS Refresh and Refresh Interval are now one setting, "Look up addresses again".
4. **The Services page lists only the services you picked.** The rest are in Browse catalogue…, under the list.
5. **The dropdown can offer the site open in your browser.** This one is optional. The first time, macOS asks for Automation permission, once per browser. Say no and the row stays hidden.

How each page works now: https://geiserx.github.io/VPN-Bypass/usage/

## What's new

- **Where a site goes.** The Status page and `vpnb why <site>` say which way a site leaves and why. The path check tells which way a routed address really goes. https://geiserx.github.io/VPN-Bypass/usage/#where-does-this-site-go-vpnb-why
- **Pause.** Stop routing for a while, or until the VPN reconnects, from the dropdown, `vpnb pause` or Shortcuts. https://geiserx.github.io/VPN-Bypass/usage/#pause-and-resume-vpnb-pause
- **Shortcuts actions.** Switch mode, turn a service on or off, or pause, so a Focus or a time of day can drive the app. https://geiserx.github.io/VPN-Bypass/usage/#shortcuts-actions
- **Learn a site.** Use a broken site for 60 seconds with the Lookups page open, then add the names it needed.
- **Stale entries.** Domains marks an entry that stopped resolving, and one that sits on a shared CDN address.
- **Profiles per network.** Each network keeps its own mode and lists, so home and office each get their own setup.
- **Regional packs.** Each country's banks and public services come as one pick in the catalogue.
- **VPN Only blocks on drop.** Listed sites stop loading outside the VPN when it drops.
- **Kill-switch warning.** The app says when a VPN kill switch means bypass can have no effect.
- **Service catalogue.** Search services by name, domain or country, and pick several at once.
